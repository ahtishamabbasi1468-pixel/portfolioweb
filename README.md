# Ahtisham Razzaq — Portfolio

Personal portfolio website showcasing my work as a Full-Stack Web Developer. Built with a dark glassmorphism design, smooth animations, and a fully responsive layout.

**🔗 Live Site:** [ahtishamrazzaq.vercel.app](https://ahtishamrazzaq.vercel.app/)

---

## ✨ Features

- **Dark / Light Mode** — theme toggle with system preference detection
- **Glassmorphism UI** — blurred glass cards with a purple-to-cyan gradient accent
- **Smooth Animations** — scroll reveals, floating elements, and a typing effect for role titles
- **Fully Responsive** — optimized for desktop, tablet, and mobile
- **Project Showcase** — live screenshots, tech tags, GitHub links, and live demo links
- **Resume Download** — one-click resume download button
- **Contact Section** — direct email integration via EmailJS
- **Quality-of-life extras** — scroll progress bar, back-to-top button, and floating WhatsApp contact button

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/ahtishamabbasi1468-pixel/portfolioweb.git

# Navigate into the project
cd portfolioweb

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will be available at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
